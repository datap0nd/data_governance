# On-screen text policy

The main film has no subtitle track or burned-in narration text. A second version, `renders/review/animatic-ko.mp4` (`index-ko.html`), carries burned-in Korean subtitles of the narration (owner request, 27 October 2026); the same subtitles are in `subtitles/wizard-ko.vtt` and `.srt` for players. Only the narration is subtitled: the film's own English titles and the Wizard screens stay as they are. Product, portal and UI names stay in Latin script (Wizard, ASAP, GSCM, BDP, NERP, "Check my data"); Galaxy models are written 갤럭시 A37. The audience is non-technical: no SQL, query, model, API or vendor AI names in the narration or in the film's own text. Say "database", "local AI" and "authorized AI".

The drawn scenes use only names, short labels and meaningful interface content: portal names, report and file names, the hunt question, the security card and the closing tagline "Every source. One answer."

The real Wizard screens are shown as they are, including their own labels (for example "Prepared by Gemini", the tool step captions and the Sources drawer). The film adds only the "Timelapse" clock and the "Real Wizard app · illustrative data" tag. The review page carries chapter navigation, scope notes and credits outside the film.
