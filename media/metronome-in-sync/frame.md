# Film composition

1920×1080, 30 fps, 120 seconds. Light mode. Seven scenes, timed by `timeline.json`, word cues in `assets/cues.json` and a deterministic GSAP draw function. No narration captions.

Metronome surfaces keep their Outfit typography, warm neutral surfaces and teal accent. Wizard surfaces follow Wizard's own B2B system: Inter, a warm work surface, white analysis panels and one cobalt accent (#315bd6), with amber, teal and green reserved for status. The muted text grey is darkened slightly from Wizard's token so it passes AA contrast at video scale. Browser surfaces use the same code-built Chrome controls. Report portals use embedded Korean text, period columns and variance triangles.

Key motion: incoming data packets, typed Flow fields and a click creating a pipeline, questions wiring to source systems, a typed Wizard question, streamed tool steps, a folding timeline, growing bars, a Check my data pass and an evidence drawer, and a closing flow from portal to checked answer. UI content is synthetic; no live service is accessed.
