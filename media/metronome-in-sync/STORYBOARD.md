# Metronome — In Sync

Quiet presentation cut • 84 seconds • 16:9 • 60 fps • 120 BPM • English • no voiceover

A film about separate business data systems made useful by Metronome. One physical metronome represents the platform; source systems appear only as distinct data windows. The middle shows task recording, a five-stage automation pipeline and nightly run results. The concept preview shows AI agents investigating ASAP and GSCM evidence before bringing a sourced insight and report. The close returns to one metronome.

This describes the current draft animatic for owner review. All timing below is a human-readable view of `timeline.json`, the single source used for picture and sound. The composition is 1920×1080; final-quality exports follow gate-2 feedback. No live product, portal, database or private data is used.

**Owner feedback incorporated:** ASAP, GSCM, Big Data Portal and Data Hub are now data windows, never metronomes. The dark fictional portal leads into a visible five-stage automation. Metronome’s collected evidence boosts AI agents as they investigate and form a report. The [animatic review](animatic-review.html) shows the full timed draft with score.
