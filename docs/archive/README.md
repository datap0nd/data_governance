of it is current guidance for people or agents; `AGENTS.md` at the repository
root and the documents it points to are the source of truth.

| --- | --- | --- |
| `instructions.md` | Windows setup guide from the "MX Analytics" scanner era. | The product is Metronome; `owners.csv` and `powerbi_links.csv` no longer have loaders. Current operator setup is in `README.md`. |
| `plan.md` | The original architecture and roadmap. | Docker Compose and Pico CSS were never adopted; the TMDL Checker was retired from navigation. |
| `pending_steps.md`, `additional_instructions.html` | One-time manual steps for adding owner tables to Power BI reports. | The referenced `update.ps1` and CSV workflow no longer exist. |
| `extra.md` | A draft email about a data discrepancy investigation. | Unrelated to the codebase. |
| `agent_handoff.md` | An August 2026 handoff between agent sessions. | Its commits predate this history and its next steps were delivered by later PRs. |
